# honig

The runtime that code generated by [honig](https://github.com/AlphaJack/honig) calls.
You do not add it by hand. `cargo honig generate` adds it to your `Cargo.toml` at the exact version of the generator (`=x.y.z`). It turns on the [features](https://alphajack.github.io/honig/adapters.html) that your dependencies and description call for.
Generated modules re-export its API at their root. Your code names `api::OperationRequest`, for example.

What your code uses is at the crate root. `Request` and `Response` are `http::Request<Body>` and `http::Response<Body>`. Bodies and items that arrive or leave a piece at a time are a `futures_core::Stream`.

Generated code also calls `__private`. It changes with the generator and is not for your code.

The server is a tower `Service` over `http` requests (`Server::into_service`). hyper serves it as it is.
