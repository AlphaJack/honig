cargo honig: OpenAPI 3.2 to a Rust client and server

Usage: cargo honig [OPTIONS] <COMMAND>

Commands:
  init      Add the module `api` to Cargo.toml and the `honig` dependency with your adapters
  generate  Generate the modules set in Cargo.toml files
  check     Fail if a module is stale
  validate  Validate under its own OpenAPI version and print diagnostics
  upgrade   Print the document upgraded to OpenAPI 3.2 JSON
  bundle    Print a description split over files as one document, in its own OpenAPI version
  help      Print this message or the help of the given subcommand(s)

Options:
      --manifest-path <PATH>  Cargo.toml to use [default: Cargo.toml]
  -q, --quiet                 Only print errors
  -h, --help                  Print help
  -V, --version               Print version

SETTINGS ([package.metadata.honig.<module>] in Cargo.toml): descriptions, output, mod_rs, client, server, operations, tests, unknown_fields, overlays, formats, derives
The Settings page of the book explains each one: https://alphajack.github.io/honig/settings.html
