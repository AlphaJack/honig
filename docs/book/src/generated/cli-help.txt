cargo honig: OpenAPI 3.2 to a Rust client and server

Usage: cargo honig [OPTIONS] <COMMAND>

Commands:
  init      Add the module `api` to Cargo.toml and the `honig` dependency with your adapters
  generate  Generate the modules set in Cargo.toml files
  check     Fail if a module is stale
  validate  Validate under its own OpenAPI version and print diagnostics
  help      Print this message or the help of the given subcommand(s)

Options:
  -m, --manifest <PATH>  Cargo.toml to use [default: Cargo.toml]
  -q, --quiet            Only print errors
  -h, --help             Print help
  -V, --version          Print version

Settings of a module: https://alphajack.github.io/honig/settings.html
